Perl для обработки текста: автоматизируйте рутину за 4 недели

Курс для аналитиков, DevOps, тестировщиков и разработчиков, которые хотят быстро разбирать логи, парсить данные и писать мощные однострочники.

Вы когда-нибудь тонули в гигабайтах логов? Вручную чистили CSV? Писали хрупкие регулярки на Python и теряли часы? Perl создан именно для этого. Это не «язык прошлого», а специализированный инструмент, который до сих пор остаётся эталоном работы с текстом.
Почему Perl?

    Регулярные выражения — часть языка. m//, s///, $1, именованные захваты — всё встроено.

    Однострочники. Одна строка в терминале — и вы уже заменили данные во всех файлах.

    CPAN. Тысячи готовых модулей: CSV, JSON, HTML, БД, HTTP.

    Unicode. Корректная работа с кириллицей и любыми языками.

    Скорость разработки. Текстовые задачи решаются быстрее, чем на многих других языках.
