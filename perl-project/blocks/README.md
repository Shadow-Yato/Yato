## Коротко о проекте
Perl — артефакт эпохи 1995–1999 годов, когда язык стал «клейкой лентой интернета»: Perl 5, CGI и CPAN сделали его главным инструментом для динамических сайтов и системного администрирования. Проект — рекламная страница вымышленных курсов «Верблюжья мастерская: 21 день, чтобы склеить интернет на Perl», где сисадмины и ранние веб-разработчики учились писать скрипты вместо тяжёлого C и хрупкого shell. Страница выполнена в визуальном языке HTML 3.2 — таблицы, серый фон, GIF, никаких скруглений и теней. Итог — репозиторий GitHub с исследованием и сайт на GitHub Pages.
